# Backend Mobile

Estructura ficticia de un backend previsto para Node.js, NestJS y TypeScript, orientado a una aplicación móvil.

## Alcance de este commit

Sólo carpetas y archivos con nombres habituales. Los archivos TypeScript contienen exclusivamente comentarios. No hay servidor, endpoints, lógica de negocio, conexión a base de datos ni integraciones.

Los archivos JSON de configuración son marcadores vacíos. `package.json` contiene sólo metadatos y listas vacías de scripts y dependencias. Los archivos de pruebas no contienen pruebas ejecutables. No se han instalado paquetes ni generado un proyecto mediante Nest CLI.

## Organización

Consulta `docs/architecture.md` para conocer la responsabilidad prevista de cada carpeta. `docs/api.md` queda reservado para una documentación futura.

## Commit inicial

Copia el contenido de esta carpeta en la raíz del repositorio, incluyendo `.gitignore`, `.env.example` y `.editorconfig`.

Mensaje sugerido:

```text
chore: agregar estructura inicial del backend
```

Este entregable no incluye un repositorio `.git` ni un commit creado. No hay comandos de instalación, compilación o arranque porque el proyecto no es funcional.
