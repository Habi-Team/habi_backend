# Organización prevista

- `src/config`: configuración.
- `src/common`: elementos compartidos.
- `src/database`: persistencia, migraciones y datos iniciales.
- `src/modules/auth`: autenticación.
- `src/modules/users`: usuarios.
- `src/modules/devices`: dispositivos móviles.
- `src/modules/notifications`: notificaciones.
- `test`: espacios reservados para pruebas.

Las responsabilidades son orientativas. No hay código implementado ni decisiones de proveedor, base de datos o versiones de dependencias.
